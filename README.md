# ASSIGNMENT-1
Descriptive Statistics Using Python

📌 Project Overview

This project explains Descriptive Statistics using Python. It uses Python libraries to analyze numerical data and understand the distribution, central tendency, and variability of data.

🎯 Objective

To perform descriptive statistical analysis using Python and visualize the data through different graphs.

🛠️ Technologies Used

Python

Jupyter Notebook

NumPy

Pandas

Matplotlib

Seaborn

SciPy

📚 Topics Covered

Descriptive Statistics

Mean, Median and Mode

Geometric Mean

Harmonic Mean

Variance and Standard Deviation

Covariance and Correlation

Percentiles

Interquartile Range (IQR)

Box Plot

Histogram

Kernel Density Estimation (KDE)

Confidence Interval

📊 Dataset

The project uses a Height and Weight dataset.

Height is converted from inches to centimeters.

Weight is converted from pounds to kilograms.

💻 Installation

Install the required Python libraries:

pip install numpy pandas matplotlib seaborn scipy jupyter

▶️ How to Run

Download or clone this repository.

Open the project using Jupyter Notebook.

Make sure the required dataset and supporting Python files are available.

Open 01_decriptive_stats.ipynb.

Run all the cells to execute the statistical analysis.

📈 Visualizations

The notebook includes:

Box Plot

Histogram

KDE Curve

Confidence Interval Visualization

📌 Conclusion

This project provides practical knowledge of descriptive statistics using Python. It helps understand numerical data through statistical calculations and graphical visualizations.
